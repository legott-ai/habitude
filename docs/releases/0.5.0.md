# Habitude Checklist 0.5.0

Keep your Markdown habit tracking free and local, and choose when to explore Habitude beyond Obsidian.

- Export habits and dated check states as a local JSON file after reviewing counts and dates. Archived habits and explicit unchecked states are preserved; original Markdown files are unchanged. Keys, settings, chats, notes, and attachments are excluded.
- Explore Habitude and compare planned monthly and annual Sync/Plus prices inside the plugin. Suggestions stay in Habitude's own views and can be hidden permanently. Visiting the website is an explicit action; habit records are not attached to links.
- Preserve unfinished inputs when hiding or restoring suggestions.
- Fix SVG graph rendering, narrow checklist scrolling, and accessible pressed states.
- Add matching English and Korean instructions.

**Sync and Plus are in preparation and are not available to purchase.** Manual transfer is free and does not enable automatic sync. BYOK provider costs remain separate. The plugin requires Obsidian 1.13.0 or newer.

Run **Export habits for Habitude** from the command palette, save the JSON in your vault, and select it under **Settings → Import from Obsidian** in a compatible Habitude app. This copies a snapshot; subsequent changes do not sync automatically.

Validation: production build, lint, unit and stress checks passed. A synthetic Obsidian 1.13.7 vault confirmed preview and JSON creation with unchanged source files. Mobile devices have not been independently tested.
