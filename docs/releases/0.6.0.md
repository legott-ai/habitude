# Habitude Checklist 0.6.0

Open the checklist and see today first.

- **Today card.** The top of the checklist shows how many of today's habits are done and asks about the next one. *Done* checks it off. It is worked out locally from your checks; no AI or network is involved.
- **Start the AI coach without an API key.** *Find local models* lists the chat models in Ollama or LM Studio on your computer and starts with one click.
- **A first run that starts somewhere.** An empty checklist offers six starter habits to add with one tap, instead of an empty grid, graphs and a share button.
- **Fits a narrow side pane.** The week grid no longer needs sideways scrolling in a narrow pane, and a *This week* button returns from another week.
- **Suggestions only at a moment that raises a question.** A card about Habitude appears when a run of three or more days has paused, or in a week with three or more checks. A new or barely used checklist shows none. Suggestions can still be hidden permanently, and nothing about them is recorded or sent.
- **The Habitude overview starts with what Habitude does**, each item marked *Available now* or *In preparation*, before the planned prices.
- **More dependable saving.** Rapid taps and edits arriving at the same time no longer lose a habit or collide on its id, and the data folder setting only accepts a safe path inside your vault.
- **The checklist follows your Habitude folder.** It refreshes when notes there are created, renamed or deleted, and ignores changes to unrelated notes. Adding or archiving a habit that fails now says so.
- **AI coach setup and errors.** A custom OpenAI-compatible endpoint asks for its base URL and model before the chat opens, error messages separate key problems from other request errors, and the greeting no longer appears twice.
- Fix interface language detection so Korean follows Obsidian's language setting.
- Matching English and Korean text throughout.

**Sync and Plus are in preparation and are not available to purchase.** Habi and the link to your own AI are in preparation as well; the plugin does not install or connect anything. BYOK provider costs remain separate. The plugin requires Obsidian 1.13.0 or newer.

Validation: production build, lint, unit and stress checks passed. The new screens were checked with sample data in a desktop browser, and the local model list against Ollama on macOS. LM Studio and mobile devices have not been independently tested.
