# Obsidian → Habitude 수동 습관 이전

플러그인 0.5.0 · 수동 이전과 유료 서비스는 별개입니다.

## 사용 순서

1. Obsidian 명령 팔레트에서 **Habitude용 습관 내보내기**를 선택합니다. 설정의 **Habitude로 습관 옮기기 → 내보내기 미리 보기**에서도 열 수 있습니다.
2. 습관 수·보관 수·일별 기록 수·날짜 범위를 확인합니다. 미리 보기에는 쓰기·업로드가 없습니다.
3. **볼트에 JSON 저장**을 선택합니다. 설정한 데이터 폴더의 `Exports/`에 사본을 만듭니다. 원본 `Habits.md`, `Log/`와 기존 내보내기를 덮어쓰지 않습니다.
4. 수동 가져오기를 제공하는 Habitude 앱에서 **설정 → Obsidian에서 가져오기**를 선택하고 JSON을 고릅니다.
5. 앱의 미리보기를 확인하고 실행합니다. 이후 두 제품의 변경은 자동으로 반영되지 않습니다.

수동 이전은 무료이며 구독·AI 크레딧·자동 소스 한도와 무관합니다. 계정과 연결된 클라우드 저장소에는 가져오기를 거절합니다. 가져온 자료의 향후 클라우드 연결은 앱의 현재 지원 범위를 따릅니다. 이전 자체로 클라우드 연결·업로드를 시작하지 않습니다.

## 파일 계약과 보존

합성 예시 [obsidian-export-v1.json](fixtures/obsidian-export-v1.json)을 앱 계약 테스트에도 사용합니다.

| 필드 | 내용 |
|---|---|
| `format`, `version` | `habitude-obsidian-export`, 숫자 `1` |
| `pluginVersion`, `exportedAt` | 플러그인 버전, UTC ISO 생성 시각 |
| `habits` | ID·제목·달력 생성일·`daily` 일정·보관 상태 |
| `checks` | 달력 날짜·습관 ID·명시적인 true/false |

보관된 습관의 과거 기록과 false를 포함하며, 기록 부재를 false로 바꾸지 않습니다. 시간대 변환으로 날짜를 옮기거나 동명의 앱 습관과 합치지 않습니다. 동일 내용은 생성 시각·배열 순서가 달라도 중복 추가하지 않습니다. 수정된 다른 스냅샷은 별도 사본으로 먼저 안내합니다.

API 키·설정·대화·저널/노트 본문·첨부·다른 Vault 파일은 제외합니다. 습관명 자체에도 개인적인 내용이 있을 수 있으므로 JSON도 비공개로 보관하세요. Markdown에 임의로 덧붙인 메모까지 보존하는 전체 Vault 백업 형식은 아닙니다.

한도는 UTF-8 JSON 10 MiB·습관 5,000개·상태 100,000개입니다. 잘못된 날짜·중복 ID/상태·등록되지 않은 습관·지원하지 않는 일정·필수 metadata 누락은 원본 수정을 안내하고 중단합니다. 읽는 중 파일이 바뀌어도 다시 미리 보도록 합니다.

앱은 적용 전 복구 정보를 저장합니다. 실패·중단은 복구하고, 이후 사용자 편집이 있으면 되돌리기가 그 편집을 덮어쓰지 않도록 거절합니다. 실제 iOS/Android 파일 선택·서명 앱과 공개 배포는 별도 검증입니다.

제품과 출시 조건은 [상세 설계서](product-and-conversion-plan.ko.md)를 따릅니다.
